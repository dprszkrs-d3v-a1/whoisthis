# whoisthis
Identify (scanner) IP addresses via WHOIS (RDAP) and geolocate them.
You need to add the GeoLite2-City.mmdb databse. It can be downloaded from the MaxMind website (https://www.maxmind.com/en/home) 
by registering an account. MaxMind GeoLite2 (also known as GeoLite) is a free IP geolocation and ASN dataset provided by MaxMind.

Key Features and Offerings

• Data Types: Available as Country, City, and ASN (Autonomous System Number) databases and web services.
• Formats: Provided in binary (.mmdb) format for fast local lookups or CSV format for integration.
• Free Tier Limits: Restricted to 30 database downloads and 1,000 web service lookups per day per service.
• Accuracy: Less precise than paid commercial GeoIP databases; returns an approximate location area defined by latitude, longitude, and an accuracy radius.

Requirements to Get Started

• Account Registration: You must register for a free user account on the MaxMind Create Account Page.
• License Key: Accessing and downloading the databases requires generating a license key inside your account portal.
• License Agreement: Governed by the MaxMind GeoLite End User License Agreement, which incorporates Creative Commons terms (CC BY-SA 4.0).
